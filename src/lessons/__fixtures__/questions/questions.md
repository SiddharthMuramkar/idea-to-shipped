## Why plans fail

Most bad output starts with an unmade decision.

```checkpoint who-owns-details
The agent asks which CSS file layout you want.
You **don't care**. Best reply?
- [ ] Research it yourself first.
  > That spends your attention on a detail.
- [x] "You decide, using best practice."
  > Right. You own the **scope**;
  > the agent owns the details.
- [ ] Skip grilling and start `coding`.
  > Skipping a decision doesn't remove it.
```
