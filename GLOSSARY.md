# Lesson Site

A small personal course that teaches Matt Pocock's skills and agentic coding, written as a journal of building this very site.

## Course

**Lesson**:
One page of the course, read in a fixed order. Most Lessons teach one Skill. Some don't ("Start here", "Models, effort & ultracode").
_Avoid_: Page, post, chapter, article

**Slug**:
A Lesson's permanent one-word identifier (e.g. `grilling`). Comments point at it, so it never changes. A Lesson's title and position number can change freely.
_Avoid_: Lesson ID, endpoint, path

**Skill**:
One of Matt Pocock's Claude Code skills (e.g. grilling, tdd) that a Lesson teaches.
_Avoid_: Command, tool, plugin

**Phase**:
One step of building this site, done with one Skill. Each Lesson is written right after its Phase ends.
_Avoid_: Stage, step, milestone

## Discussion

**Comment**:
A note a Visitor leaves on one Lesson. It has a body and an optional name, and can't be edited after it's posted.
_Avoid_: Message, feedback, post, reply

**Visitor**:
Anyone reading the site. Visitors are anonymous and have no accounts.
_Avoid_: User, member, commenter
