# 01 — Scaffold the app

Status: resolved
Blocked by: —

## What
Create the Next.js app (App Router, TypeScript) in the repo root with Vitest and one plain CSS file holding the base look from the spec. `git init`, add a `.gitignore` (including `.env*.local`), and make the first commit.

## Done when
- `npm run dev` shows a placeholder home page with the spec's look (white, royal blue, sharp corners).
- `npm test` runs and passes (one trivial test).
- `npm run build` succeeds.
- No Tailwind, and no database code yet.
